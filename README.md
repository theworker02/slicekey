# slicekey

Slice validation gates for key inputs before they hit prod.

**Site:** https://theworker02.github.io/slicekey/

## Install / run

```bash
git clone https://github.com/theworker02/slicekey.git
cd slicekey
node src/cli.js
node --test
```
